Binary game

Rows fill the column from the top. Set the bits when a decimal is showing, or type the decimal when the bits are already set. Clear a row before the column is full.

Warm-up is slow. After eight clean rows, pick 1, 2, or 5 minutes and score as many points as you can. A faster row is worth more, and the next row arrives based on how fast you have been clearing.

How a row works

  1. Number on the right. Tap bits until the 1s add up to it. The row clears on its own.
  2. Blank on the right. The bits are fixed. Tap the box and type their total with the keyboard, then press Enter.
  3. A miss stays up. Read the working, then try that row once more.
  4. The column fills. Six rows fit. One more arrival ends the round.
  5. Then the clock. After warm-up, pick 1, 2, or 5 minutes. Faster clears score more.

Tap a row to select it. On a bit row, keys 1–8 flip columns from the left. On a decimal row, type with the keyboard. Enter submits. P pauses.

Ways to see a byte

  • The rightmost bit is the 1. It is on for every odd number, and off for every even number.
  • Take the largest place value that still fits, subtract it, and repeat with what is left.
  • One less than a place value is a run of 1s to its right. 16 − 1 is 0000 1111. 128 − 1 is 0111 1111.
  • All eight bits on is 255. An IPv4 octet lives in that range.
