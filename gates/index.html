    How a puzzle works

    1. Read the expression. Brackets and order matter.
    2. Build the schematic. Tap an empty port or gate, pick an input or a gate, nest as needed.
    3. Watch the table. It updates from your circuit. Play the signal run to see every row flow.
    4. Check when ready. Any circuit with the same truth table wins. Faster builds earn a speed bonus.

    Keyboard: Tab through ports, Enter to place, Esc closes the picker, C checks, P pauses, Space steps the signal run when focused in the lab.

    Ways to see a gate

    • AND is only 1 when every input is 1. OR is 1 when any input is 1.
    • NOT flips a single wire. NAND and NOR are AND/OR with a NOT on the result.
    • XOR is 1 when the inputs disagree — useful for “one or the other, not both”.
    • Two circuits can look different and still share a truth table. Matching is by behaviour.
